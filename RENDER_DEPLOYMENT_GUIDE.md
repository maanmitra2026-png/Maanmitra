# MAANMITRA — Render Deployment Guide

## Architecture Overview

```
Internet
  │
  ├── maanmitra-frontend  (Render Static Site — Free plan)
  │       React 18 + Vite SPA served via Render CDN
  │       All routes → /index.html (SPA rewrite)
  │
  ├── maanmitra-backend   (Render Web Service — Starter plan)
  │       FastAPI + Uvicorn (2 workers)
  │       WebSocket support via uvicorn[standard]
  │       Persistent /app/uploads disk (1 GB)
  │       Health check: GET /api/v1/health
  │
  └── maanmitra-db        (Render PostgreSQL — Free/Starter)
          Region: virginia (same as backend)
```

## One-Click Deploy via Blueprint

The `render.yaml` in the repo root is a **Render Blueprint**. To deploy:

1. Push the repo to GitHub/GitLab
2. Go to **https://dashboard.render.com** → **New** → **Blueprint**
3. Connect your repo → Render auto-detects `render.yaml`
4. Set the secret env vars **manually** in the dashboard (see below)
5. Click **Apply** — all 3 services deploy together

---

## Secret Env Vars (Set in Dashboard — NOT in render.yaml)

After Blueprint deploys, go to each service → **Environment** and set:

### Backend Service (`maanmitra-backend`)

| Key | Value | Notes |
|---|---|---|
| `RAZORPAY_KEY_ID` | `rzp_live_...` | From Razorpay dashboard |
| `RAZORPAY_KEY_SECRET` | `...` | Keep secret |
| `CORS_ORIGINS` | `https://maanmitra-frontend.onrender.com` | Your frontend URL |

> `JWT_SECRET` and `DATABASE_URL` are auto-generated by render.yaml — no action needed.

### Frontend Static Site (`maanmitra-frontend`)

| Key | Value | Notes |
|---|---|---|
| `VITE_RAZORPAY_KEY_ID` | `rzp_live_...` | Same as above |
| `VITE_API_URL` | `https://maanmitra-backend.onrender.com/api/v1` | Your backend URL |
| `VITE_WS_URL` | `wss://maanmitra-backend.onrender.com/api/v1` | WebSocket (wss://) |

> After setting env vars, trigger a **Manual Deploy** on the frontend so Vite bakes the new URLs.

## Custom Domain Setup

1. Go to **Dashboard → maanmitra-frontend → Settings → Custom Domains**
2. Add `www.maanmitra.com` and `maanmitra.com`
3. Update your DNS with the CNAME provided by Render
4. Update `CORS_ORIGINS` on the backend to include `https://www.maanmitra.com`

## WebSocket Support (Real-Time Chat/Calls)

Render Web Services support WebSockets out-of-the-box. The backend uses:
- `uvicorn[standard]` with `--ws websockets`
- FastAPI's `WebSocket` for `/ws/maanmitra/chat/{session_id}`
- FastAPI's `WebSocket` for `/ws/maanmitra/signaling/{session_id}`

**Free plan caveat:** Services sleep after 15 min of inactivity → WebSocket connections drop.  
**Fix:** Upgrade to **Starter plan** (always-on) for production.

## File Uploads (Profile Photos)

The backend mounts a **1 GB persistent disk** at `/app/uploads`.

> Files uploaded on the Free plan are stored on ephemeral storage and **lost on redeploy**.  
> The persistent disk on the Starter plan survives deploys and restarts.

## Local Development

```bash
# Backend
cd backend
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
cp .env.example .env          # fill in values
uvicorn app.main:app --reload --port 8000

# Frontend (new terminal)
cd frontend
cp .env.example .env          # fill in values
npm install
npm run dev                   # → http://localhost:5173
```
